Modern React Web Application

A clean, responsive, and high-performance multi-page web application built with **React** and **Vite**.

🚀 Features

* **Component-Based Architecture:** Modular components for Navbar, Footer, and individual pages.
* **Client-Side Navigation:** Seamless state-based page switching between Home, About, and Contact.
* **Responsive Design:** Fully optimized layout for mobile, tablet, and desktop screens using modern CSS Flexbox and Grid.
* **Interactive UI:** Smooth transitions, active link indicators, and custom form styling.

🛠️ Tech Stack

* **Frontend:** React (JSX)
* **Build Tool:** Vite
* **Styling:** Vanilla CSS (Custom properties, responsive media queries)
* **Icons / Assets:** SVG & Modern CSS Gradients

⚙️ Getting Started

To run this project locally, follow these steps:

Prerequisites

Make sure you have Node.js installed on your machine.

Installation

Clone the repository or open your project folder in the terminal:

Bash
cd website

Install dependencies:
Bash
npm install

Run the development server:
Bash
npm run dev

Open your browser and visit the local URL provided by Vite (usually http://localhost:5173).

📜 Scripts
npm run dev - Starts the local development server.

npm run build - Builds the app for production in the dist folder.

npm run preview - Locally preview the production build.
